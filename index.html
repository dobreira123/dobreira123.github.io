多益單字測驗 PWA

為準備多益而開發的單字學習網頁，手機可加到主畫面、離線使用。從需求規劃、介面設計到部署上線皆獨立完成，開發過程搭配 AI 工具（Claude Code）協作。

  • 六種測驗模式：英選中、中選英、聽音選字、例句填空、拼字（標示拼錯的字母位置）、字卡
  • 間隔重複複習：答錯的字依 1／3／7／14 天排程，首頁顯示今日待複習
  • 學習統計：每日答題數、正確率趨勢圖、各分類熟練度、連續學習天數
  • 內建 1,500 字單字庫（基礎／銜接／高頻），也可匯入自訂 CSV
  • Web Speech API 英式／美式發音切換
